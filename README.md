# ROCK.PLAYLIST — Party set builder

A responsive, single-page starter inspired by the broad interaction concept of NAUX, with original ROCK.PLAYLIST branding, layout, copy and styling.

## Run locally
Open `index.html` in a browser. For a local dev server, run:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000.

## Included
- Responsive dark editorial landing page
- Vibe selection and playlist set builder
- Language and duration selectors
- Tracklist display and copy action
- Explore-set cards and navigation

## Important before launch
The current playlist generator is a front-end demo with a small sample track catalogue. It does not stream music. To enable playback, connect a licensed provider (for example, Spotify or YouTube where permitted), implement authentication/API requirements, and confirm commercial-use and playback terms. Do not scrape or redistribute copyrighted audio.
